# Codexへの初回開発指示

あなたはVRChat Worlds / Unity / UdonSharpの開発担当です。作業開始前に、このリポジトリの `AGENTS.md` と `Documentation/VRC_骨の口保持ギミック_設計書.md` を読み、`Reference/Prototype/` の試作コードを確認してください。

**目的:** 設計書のPhase 1「口位置推定と可視化」を、安全にUnityで検証できる実装にしてください。既存のVRC Pickupによる手での操作は維持します。

**作業:**
1. UnityプロジェクトとPackagesに存在するVRChat SDK/UdonSharpの実際のバージョンと構成を調査してください。情報が取得できなければ未確認と記録してください。
2. 試作コードについて、APIの存在・UdonSharp対応・数学的な整合性をレビューし、重大な問題を先に報告してください。SDKの確証がないAPIは推測で断定しないでください。
3. Phase 1に必要なファイルだけを編集または追加してください。頭部追跡、Head Bone補正、スケール補正、ローカルデバッグ可視化を対象とし、Contact取得・口保持・所有権同期の実装はこのタスクでは変更しないでください。
4. 実際に実行可能なチェックを行い、実行できなかったUnity/UdonSharpコンパイルは未検証と明示してください。
5. 修正ファイル一覧、仕様との対応、Unity Inspectorの設定方法、テスト手順、既知の問題を日本語で報告してください。

**制約:** アバター改変・ユーザーキャリブレーションは不可。VRChat公式APIのみを原則として使用し、一般的なUnity C#で使えてもUdonSharp非対応のAPIは導入しないでください。UnityのScene・Prefab・metaやSDKバージョンを無断で書き換えないでください。既存の骨の手Pickupを壊さないでください。
